# UI・UX改善計画

更新: 2026-09-07

## 目的と現在地

「可能な限り最高のUI・UXに改善する」を、設定 → 実行 → 結果を探す → SEOを読む → 画像を確認する一連の操作として改善する。
既存のTauri / Vue構成、SiteOne連携、複数サイズ、保存データと許可パスの境界、青・冷灰の基本デザインを維持する。
任意確認に回答がなかった内容を、新しいデザイン方針の承認とは扱わない。

計画した実装と主要操作の受入は完了した。画像モーダルだけでなく設定、実行、結果一覧、SEO、狭幅を含む。
詳細な検証結果と画面証拠は、リポジトリ内には保持していない。

## 改善範囲

| 領域 | 実装した状態 |
| --- | --- |
| 視覚設計 | 文字階層、補助説明、余白、共通SVGアイコン、コントロールの高さを統一する。 |
| 設定 | 折りたたみ、直接編集、サイズの追加・削除、有限整数検証とエラー説明、キーボードフォーカスを提供する。 |
| 実行と復旧 | 開始待ち・実行中・停止中・完了・失敗を区別し、開始連打、旧結果、遅延応答、設定保存の競合を抑止する。 |
| 結果を探す | グリッドと1ページ1行の切替、検索・解除・ゼロ件、サイズ絞り込み、並べ替え、件数を一貫させる。 |
| SEOを読む | URL列を固定し、title / description / canonical / OGP・Twitter / H1 / H2を詳細展開で全文確認できる。 |
| 画像を確認する | ページURLとサイズIDの対応から実画像を開き、全体／100%表示、未取得・失敗・再試行、Escapeとフォーカス復元を提供する。 |
| 画面サイズと入力方法 | ブラウザ1440・1180・885・390pxの幅を考慮し、狭幅では設定ドロワーとツールバー折り返しを使う。 |
| 実環境 | Tauriで保存・復元から複数サイズのクロール、SEO行、実画像表示まで接続する。 |

## 実施方針

1. 入力・キーボード・誤解を招く状態表示を先に修正する。
2. Impeccableの基準を使い、既存デザイン内で読みやすさと操作の一貫性を整える。
3. 設定、実行フィードバック、結果検索とSEO詳細、画像確認を統合する。
4. 対象サイズと主要状態をまとめて確認し、発見した不具合を一括修正する。
5. 検証は必要十分な範囲に限定し、無関係な微調整や追加クロールを重ねない。

実機確認で判明した子プロセスの終了誤判定、結果取得時の空のサイズ設定参照、WebKitのモーダル画像切れも修正した。

## 引き渡しと境界

- CLI未対応のCookieバナー設定は保存値を維持したまま無効化し、未対応と明示する。
- SEO値はSiteOneのレポートに基づく。取得されなかったcanonical等を推測して補完しない。
- 実機停止はクリック前にクロールが完了したため未確認。停止成功とは報告しない。
- 初期はluna_maxが実装し親エージェントがレビューした。最新の「サブエージェント使わなくてもいいよ」に従い、仕上げと検証は親エージェントが直接実施した。
- QAの出力・設定・アプリは通常版と分離した。通常版のインストール先、設定、実行中アプリは変更していない。
- 公開、インストール先の置換、署名・公証、コミットはこの計画に含めず、別途依頼がある場合に実施する。
